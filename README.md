# Nifty AI Market System

Autonomous NIFTY market intelligence: Dhan feed, order flow, alerts, confidence engine, backtester, auto-learning, risk manager.

## Modules

- `dhan_client.py` / `dhan_feed.py` — Dhan data
- `order_flow.py`, `options_analyzer.py`, `market_regime.py`
- `confidence_engine.py`, `model_manager.py`, `auto_learner.py`
- `alert_system.py`, `backtester.py`, `risk_manager.py`, `auto_trader.py`
- `event_bus.py`, `queue_system.py`, `memory_manager.py`, `plugins/`

Configure via `config.yaml` (secrets via env).
